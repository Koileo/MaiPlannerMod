# 合并版界面与稳定性优化 · 2026-11-07

## 界面

- 默认进入歌曲点歌台；移除无操作价值的数据同步页，旧 `#db` 自动返回点歌台。顶部显示连接状态和曲库数量。
- 桌面保留歌曲、助手、卡池、玩家四个入口。常驻搜索支持回车提交，并可与版本、谱面类型等筛选组合。
- 曲卡使用正常字号和响应式列宽，显示谱面难度、定数、达成率和成绩状态。曲目标题与按钮支持键盘操作，难度保留游戏配色。
- 全局手机入口展开二维码，可复制局域网地址。手机页面使用独立模块、整行难度按钮和底部点歌反馈；成功后标记最近选择的难度。
- 手机断线时禁用点歌，重连后恢复；游戏尚未生成曲库时先显示等待，曲库就绪后自动补载。失败时可自动或手动重试。
- 修复助手页通过地址直接进入时未加载牌桌的问题，切换用户后刷新当前助手数据。

## 稳定性

- 主线程队列取消尚未执行的超时任务，每帧处理任务累计达到 4ms 后让出余下任务；单个已开始的 Unity 调用无法中断。
- 游玩状态由游戏主线程采样，HTTP 线程只读取缓存。
- 曲绘优先使用游戏已经持有的资源，避免重复打开包；仅释放自行创建的对象。不可读或压缩贴图通过 GPU 拷贝成 RGBA 后编码 PNG。
- 扫描所有版本的曲绘目录；PNG 缓存达到上限时逐张淘汰，读取失败缓存 10 秒，超时不会导致永久缺图。
- 收藏与黑名单采用受锁保护的读取和修改；文件写入使用唯一临时文件和原子替换，避免并发刷新时的 `.part` 文件冲突与丢失更新。

- 主线程、并发落盘和资源所有权自检：20/20 通过，Unity 类型使用替身。
